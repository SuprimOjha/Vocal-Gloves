# Vocal Gloves image assets

Add your project images to this folder using these filenames (or update the image paths in the root README):

- `vocal-gloves-overview.jpg` — full project overview
- `vocal-gloves-hardware.jpg` — close-up of glove hardware
- `vocal-gloves-receiver.jpg` — receiver unit
- `my-vocal-gloves-photo.jpg` — a photo of the project creator wearing the gloves

Supported formats include JPG, PNG, and WebP. If you use a different extension, update the corresponding Markdown image path.
